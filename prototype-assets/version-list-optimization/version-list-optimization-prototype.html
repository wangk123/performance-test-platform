优化点说明

  • 1问题 · 信息密度低：每版本独立卡片 + 纵排四段信息，单版本占约 3 行高，版本多时页面被撑长、留白浪费。
  • 2问题 · 无演进感：版本号与说明平铺，看不出时间先后，也分不出哪个是当前最新基线。
  • 3问题 · 操作喧宾夺主：「查看全文 / 回滚」独占一行，次要操作占据了主要视觉空间。
  • A单卡片 + 分隔线：版本收进一张卡片，行间分隔线替代独立边框，行高压缩约一半。
  • B时间轴节点：左侧竖线 + 圆点表达版本演进顺序；最新版本实心高亮 + 光环，一眼定位。
  • Cmeta 内联：修订人 / 时间合并为一行分隔点样式；操作按钮右对齐与行垂直居中，行 hover 时才高亮为品牌色（默认弱化为灰，减少噪声）。
  • D「最新」徽标：标记列表头节点，配合「有未发布的变更」提示，快速判断快照基线；「报告发布」类型徽标位置保留（本次数据无 PUBLISH 版本故未展示）。
  • 4问题 · 冗余字段：行尾的「阶段」字段（如 DRAFT）信息价值低，且历史版本存的是旧状态机裸枚举，显示出来反而造成困惑。
  • E移除「阶段」字段：meta 仅保留 修订人 · 时间；该字段不再展示，前端对应删除 statusLabel 渲染。
