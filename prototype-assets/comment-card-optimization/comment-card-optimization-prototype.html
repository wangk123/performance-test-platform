改动点

  • 1删除 rev 徽标：rev 23 是批注创建时文档正文的修订号快照（bodyRevision），纯展示性元数据，前后端均无锚定逻辑消费，对评审者无意义。
  • 2删除引用块：被批注的原文不再展示，需要上下文时点「定位」跳到正文处查看，避免长引用把卡片撑高数倍。
  • 3动作并入首行：定位 / 解决 / 删除文字按钮整行删除，改为首行右侧 22px 图标按钮（hover 有底色反馈 + Tooltip），底部动作行整体消失。
  • 4新增编辑：批注内容支持修改，铅笔图标进入编辑态（与删除同样仅本人可见）。
  • ＋首行加头像占位：20px 圆形首字符头像，按人名取色区分，后续可平滑替换为真实头像。

空间收益

  • 单行批注卡片高度约 150px → 98px，省 ~36%；
  • 长引用批注（原十二章那条 10 行引用）由 ~230px 降到 ~98px，省 ~57%；
  • 同屏可见批注数量约提升 60%–100%，滚动显著减少。

交互与无障碍要点

  • 图标按钮常驻显示（非悬停才出现），默认 55% 弱化、悬停增强 —— 避免违反「唯一动作不得仅 hover 触达」的无障碍红线。
  • 每个图标带 aria-label + Tooltip（落地用 a-tooltip），键盘 focus-visible 有描边；「已解决」状态保留文字徽章，不只靠颜色。
  • 340px 侧栏的首行预算：头像 20 + 作者（超宽省略）+ 时间压缩为「09:55:15」（完整日期时间入 Tooltip）+ 状态徽章 + 4 图标 ≈ 266px，实际可用 294px，留 28px 弹性。
  • 删除为危险色 hover；「解决 ↔ 重新打开」同一位置切换图标（✓ / ↺），不增按钮。
  • 图标可见性沿用现有权限位：canResolve / canDelete 门控，编辑新增 canEdit（仅本人）；无 anchorLine 时隐藏定位。

落地映射

  • 组件：PlanCommentCard.vue（文档侧栏与评审工作台 .workbench-list 共用，一处改两处生效）；样式：plan-module.css 的 .anno-card-* 系列整体替换为 .oc-*。
  • 图标取自现有依赖 @ant-design/icons-vue：AimOutlined（定位）/ EditOutlined（编辑）/ CheckOutlined（解决）/ UndoOutlined（重新打开）/ DeleteOutlined（删除）。
  • 编辑需要后端配套：批注域服务（PlanCommentService）当前只有增删查，需补 PATCH 端点 + canEdit 权限位；头像先按人名首字符 + 哈希取色占位。
  • bodyRevision 仅从卡片 UI 移除，字段保留在数据层，不阻塞本改动。
