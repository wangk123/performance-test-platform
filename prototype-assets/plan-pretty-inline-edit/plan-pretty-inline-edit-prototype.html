交互规则与边界

a编辑互斥与焦点

  • 同时只有一章处于编辑态：编辑中点击其他章铅笔 → 若有未保存修改先弹确认，确认后切换。
  • 进入编辑自动 focus 第一个可编辑块；Esc 取消、⌘/Ctrl+S 保存。
  • 编辑态下该章的批注「＋」悬浮按钮与批注高亮暂停，保存恢复。

b保存与冲突（链路不变）

  • 保存 = 章内容重组 → replaceSection 整文提交，revision 冲突走现有三选一冲突弹窗。
  • 保存成功后章内表格/图片立即以阅读态重新渲染（编辑态退出）。
  • 表格序列化保持现有契约：指标章强制规范表头，其余章节保留文档原表头。

c特殊章节与兼容

  • 六、测试约束（清单勾选）、八、场景设计（场景卡片）：交互模块章不提供行内编辑入口。
  • 解析失败的非常规表格（列数不齐等）：该块降级为文本块编辑，不阻塞整章编辑。
  • ChecklistView / ScenarioDesignModule 渲染与批注层（anchor 行扫描）不受影响。

d可访问性与暗色

  • 图标按钮全部带 aria-label / title；focus 可见（主题色 outline）。
  • 行/列删除为 hover 浮现 + 键盘可达（Tab 聚焦即显现）。
  • 编辑态配色全部走 token，明暗主题自动适配（右上角可切换预览）。
