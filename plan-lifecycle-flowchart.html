已实现状态
单一 PlanStatus 五值（V7 迁移完成）；phase 双枚举已删除，本图与代码一致。
评审循环（状态不动）
有异议 → 不改状态：直接修改文档＋批注沟通，改到通过为止；无驳回/撤回/重新提交。
执行联动：不回写状态
执行生命周期 QUEUED→RUNNING→SUCCESS/FAILED/INTERRUPTED（STOPPING→CANCELLED）不回写计划状态；每次执行到达终态即回填正文（revision+1 为内部计数，UI 不外露）。
软门禁 ≠ 硬拦截
前端弹窗二次确认，不阻断流转；后端已删除发布前活跃执行 409 拦截，activeExecutions 随 PlanResponse 下发。
版本记录（不可变）
发布同步登记 kind=PUBLISH 版本（快照：body·场景·摘要）；「新增版本」kind=MANUAL 同机制。
一稿走到头
同一份 Markdown 正文走完 计划→评审→执行→报告→发布；body 唯一数据源（11 章节中文序号），Pretty 视图＝受约束章节提取展示。
编辑与批注：任意状态可用
编辑 / 行内编辑 / AI 润色任意状态开放（含已发布）；PUT /document 带 baseRevision，不一致 409 三选一；批注同理。
评审批注工具
锚点批注 / 回复 / 解决 / 重开；作者·负责人可编辑批注内容，锚点不可改；原「限草稿/评审」限制已删除。
发起执行门禁 assertExecutionAllowed
① status ∈ {EXECUTING, REPORTING}（REPORTING 支持复测）　② 每个场景已关联脚本版本　③ precheck 启用 → 首次执行自动运行：失败阻断，可「跳过」留痕（系统批注）　④ 场景增删改仅活跃执行期间冻结。
发布时自动回填
冻结快照前自动回填：执行结果总览 / 判等表 / 总体结论行；硬校验仅两项——总体结论＋版本号必填、非法状态 409。
发布后：终态不冻结
可编辑 / 可批注 / 可新增版本；share 分享 → 只读链接 /share/plans/{token}（默认 30 天 · 可吊销）。

图例与全局规则
  • 矩形=状态（单一 status 五值枚举）｜胶囊=流转动作｜虚线框=旁路/说明｜⚠=软门禁二次确认
  • 单行道四流转：submit → approve → finish-execution → publish；无任何回退/回滚动作（驳回/撤回/退回草稿/新修订已删除）
  • 批注/编辑任意状态可用；已发布不冻结（可编辑·可新增版本·可分享）；场景增删改仅活跃执行期间冻结
  • 版本与状态解耦：任意状态可「新增版本」，版本号手输、不自动 +1；revision 为内部并发计数，UI 不展示
  • 执行不回写计划状态，执行终态即时回填正文；全部动作门槛＝项目成员级（角色细分延后）
实现说明（2026-09-11 简化落地）：phase×status 双枚举合并为单值 PlanStatus（Flyway V7 迁移）；删除 start-review / reject / withdraw / back-to-draft / new-revision，新增 finish-execution，approve 直达执行；publish 删除活跃执行 409 拦截（改前端软门禁）且发布后不再冻结；版本号一律手动输入，发布动作同步登记 kind=PUBLISH 版本与发布快照。
